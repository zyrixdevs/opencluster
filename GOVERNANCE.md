# Governance

## Current status

OpenCluster is an early-stage project maintained under the ZYRIX DEVS organization. This document describes the initial decision process; it does not claim that any individual account has repository or organization permissions. GitHub's actual access controls are authoritative.

## Decisions

Routine changes are proposed in issues or pull requests and discussed in the open. Significant product, architecture, security, and compatibility decisions should include rationale in `docs/DECISIONS.md`. Maintainers responsible for repository administration make merge and release decisions using the repository's configured branch protections and review requirements.

Contributors may participate in discussion and submit pull requests. Maintainer status, write access, CODEOWNERS eligibility, and review permissions are granted only through verified GitHub organization and repository settings; they are not conferred by this policy or by a listed username.

## Changes to governance

Propose changes through a pull request with a rationale and an opportunity for community discussion. Until a broader maintainer group and voting process are formally established, the repository's authorized maintainers decide whether to adopt the proposal.

## Releases and conflicts

Release cadence, version-support windows, and a formal maintainer succession process are not yet established. Participants must disclose relevant conflicts of interest in a decision discussion. A person directly involved in a conduct or security report should not be its sole adjudicator.
