# Support

OpenCluster is an early-stage project. It has no released application, service-level commitment, or guaranteed response time.

- **How-to questions and design discussion:** use GitHub Discussions if enabled for the repository. Otherwise, open a clearly titled issue and mark it as a question.
- **Bug reports:** use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml). Include the commit, environment, expected behavior, actual behavior, and safe reproduction steps.
- **Feature proposals:** use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.yml) and explain the user need.
- **Security concerns:** follow [SECURITY.md](SECURITY.md); do not disclose vulnerabilities publicly.

Please search existing discussions and issues before opening a new one. Do not include credentials, private keys, tokens, personal data, or unredacted logs.
